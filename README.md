**Kentroo** is a SaaS platform for personal trainers, built with **Laravel, Vue 3 and TypeScript**.

It is designed to help fitness professionals manage their work through a modern product experience, combining backend architecture, frontend usability and product-oriented development.

Through Kentroo, I’ve worked across the full product lifecycle: architecture, implementation, UI development, backend logic, testing, deployment considerations and continuous product iteration.

Current status:
Private beta currently being validated with real personal trainers, focusing on workflow optimization, client management and product-market fit.
